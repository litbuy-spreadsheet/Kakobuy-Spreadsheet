## How to use this resource

1. [Open the Kakobuy catalog](https://fashion-reps.net/kakobuy-spreadsheet).
2. Browse a category or search for a product.
3. Read the listing, check measurements and review available QC evidence.
4. Select Kakobuy in the website's shopping-agent selector.
5. Open the purchase link and confirm the item, options, fees and shipping with the agent.

[Read the ordering guide](https://fashion-reps.net/how-it-works)

## Frequently asked questions

### Is this an Excel or Google Sheets download?

This repository is a navigation guide to a web-based product catalog. Browse the live site for current listings.

### Can I use Kakobuy?

Fashionreps lists Kakobuy among its shopping-agent choices. Select your agent on the site before opening purchase links.

### Does every product have QC photos?

Check each listing for available images and evidence. This guide does not promise QC photos for every item.

### Where are orders handled?

Orders, payments and shipping are handled on the shopping agent's website. Verify current prices, availability and terms there.
